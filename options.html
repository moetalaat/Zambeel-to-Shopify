Zambeel to Shopify settings

Connect your Shopify store once. After that, importing a Zambeel product is one click.

Use the .myshopify.com domain, not your custom domain. Find it in your admin URL: admin.shopify.com/store/your-handle becomes your-handle.myshopify.com.

Where do I get these? (new Dev Dashboard)
  1. In Shopify admin: Settings > Apps and sales channels > Develop apps > Build apps in Dev Dashboard.
  2. Create app, name it "Zambeel Importer".
  3. In the app, open API access (or Configuration) and add the Admin API scopes write_products, read_products, write_publications and read_publications. Save. (The publications scopes let imports auto-publish to your Online Store.)
  4. Install the app on your store (pick your store, approve).
  5. Open the app's Settings (or Overview) and copy the Client ID and Client secret into the fields above.

The extension trades these for a 24-hour Admin API token and refreshes it automatically. Both are stored only in this browser and sent only to your own store.

Replaces the supplier so customers can't tell you're dropshipping. The importer also strips "Zambeel" from titles, tags, and image alt text automatically. Leave blank to leave Vendor empty.

The popup shows only this market's variants and hides the other, so you never see UAE while selling KSA. Each product's country selector is dropped on import, so customers never see it. "Both" shows every country and lets you pick per product.
